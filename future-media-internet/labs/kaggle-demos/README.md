## Classroom Flow

- **Session 1**: Demo 1 (10 min) -> Demo 2 (12 min)
- **Session 2**: Demo 5 (10 min) -> Demo 6 (8 min) -> Demo 7 (8 min)
- **Brief mentions**: Demo 3, Demo 4

## Update

Treat Kaggle as the latest version. Run `python sync_kaggle_demos.py`, review
`git diff`, then commit the synchronized notebooks to GitHub.
