# FMI 课程 AI 实验——教师准备清单

## 课前准备（一次性）

### 1. Kaggle Demo Notebook 部署

将 `kaggle-demos/` 目录中的 5 个 `.ipynb` 文件上传到 Kaggle：

1. 登录 Kaggle → Create → New Notebook
2. File → Upload Notebook → 选择对应 `.ipynb` 文件
3. 点击 **Run All** 执行一遍
4. **Save Version** → 选择 "Save & Run All (Commit)"
5. Settings → Sharing → Public

所有 Demo 均可在 Kaggle 免费 CPU 环境运行，无需 GPU。

推荐顺序：
- 第一节课：demo1（10 min）+ demo2（12 min）
- 第二节课：demo5（10 min）

### 2. 本地环境验证（可选）

如果计划在本地演示，运行环境检查脚本：

```bash
pip install numpy pandas matplotlib scikit-learn scapy torch torchvision jupyter seaborn
python check_env.py
```

### 3. 学生材料分发

以下材料需在第一次实验课前发给学生：
- `labs/README.md`（实验总索引+评分汇总）
- 各实验的 `exp*/README.md`（指导书）
- 各实验的 Kaggle Demo 链接

## 课堂教学流程（建议）

### 第一次实验课（2 学时）

| 时间 | 内容 | 备注 |
|---|---|---|
| 0-10 min | Kaggle 运行 demo1（流量分类） | 投影演示 |
| 10-20 min | 讲解实验一评分标准 + 分步操作 | 学生跟看 |
| 20-30 min | Kaggle 运行 demo2（QoE 优化） | 投影演示 |
| 30-40 min | 讲解实验二评分标准 | |
| 40-45 min | 学生当场配置环境 | 教师巡场 |

### 第二次实验课（2 学时）

| 时间 | 内容 | 备注 |
|---|---|---|
| 0-10 min | Kaggle 运行 demo5（语义通信） | 投影演示 |
| 10-20 min | 讲解实验五评分标准 | |
| 20-30 min | 快速过实验三、四的 demo | 简要展示 |
| 30-45 min | 学生自主选择进阶实验 | 教师答疑 |

## 常见学生问题预案

| 问题 | 回答 |
|---|---|
| "我没学过 Python" | 提供 [Kaggle 版本](kaggle-demos/)，填空式代码，改几行就跑 |
| "环境装不上" | 直接用 Kaggle Notebook（浏览器里跑，零配置）|
| "RL 太难" | 实验二的 Q-learning 只需补 5 行代码，模板已给 |
| "训练太久" | Kaggle CPU 训练 MNIST 只需 2 分钟 |
| "想要 GPU" | Kaggle 免费提供每周 30 小时 GPU |

## 评分提交

学生需提交：
- 完整的 Jupyter Notebook（含所有代码和输出）
- 一份分析报告（PDF，≤ 1000 字）

提交方式：GitHub Classroom 或学校 LMS，由教师自行决定。
